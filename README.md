# Buna (بُنّ) — downloads

**Buna** is a cafeteria management system for Windows: point of sale, stock, purchases, expenses, reports and accounting, with a full Arabic interface.

- Website and live demo: https://buna-cafeteria.vercel.app
- Latest installer: see [**Releases**](../../releases)

## Install

1. Download `Buna-Setup-<version>.exe` from the latest release.
2. Run it. The installer is not code-signed yet, so Windows SmartScreen may say "Windows protected your PC": choose **More info → Run anyway**.
3. On first launch choose **Start free trial** (7 days) or enter your licence key. An internet connection is needed for the trial and for activation.
4. Change the default administrator password right after your first sign-in.

Requirements: Windows 10 or 11, 64-bit.
