## Buna 2.0.0 (first release under the new name)

**Installer:** `Buna-Setup-2.0.0.exe` (Windows 10/11, 64-bit, about 91 MB)
**SHA-256:** `905662702169b3d1bbb13d07ce556db2cd869ce892127062567bb824ccd27b26`

### New
- Product renamed **Buna / بُنّ**.
- **Free 7-day trial** from the first screen, then activation with a licence key bound to your computer (digitally signed licences, works offline between periodic online checks).
- Cleaner starting point: the installer no longer ships a pre-filled database, so every installation starts empty.

### Notes
- **Pre-release:** trial and key activation need the Buna licensing service, which is being rolled out. Until it is live, activation may show "cannot reach the licensing server". Please try again later or contact us.
- The installer is not code-signed yet: on Windows SmartScreen choose **More info → Run anyway**.
- Change the default administrator password after the first sign-in.

Website & live demo: https://buna-cafeteria.vercel.app
